## 2.1.98

- ログイン画面で「3rd-party platform」を選択した際にアクセスできる、インタラクティブなGoogle Vertex AIセットアップウィザードを追加。GCP認証、プロジェクトとリージョンの設定、認証情報の検証、モデルの固定をガイドします
- `CLAUDE_CODE_PERFORCE_MODE`環境変数を追加：設定すると、Edit/Write/NotebookEditが読み取り専用ファイルに対して失敗し、サイレントに上書きする代わりに`p4 edit`のヒントを表示します
- バックグラウンドスクリプトからのイベントをストリーミングするMonitorツールを追加
- `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB`が設定されている場合、Linux上でPID名前空間分離によるサブプロセスサンドボックス化を追加。また、セッションごとのスクリプト呼び出しを制限する`CLAUDE_CODE_SCRIPT_CAPS`環境変数を追加
- printモードにクロスユーザープロンプトキャッシングを改善する`--exclude-dynamic-system-prompt-sections`フラグを追加
- ステータスラインのJSON入力に`workspace.git_worktree`を追加。現在のディレクトリがリンクされたgit worktree内にある場合に設定されます
- OTELトレーシングが有効な場合、Bashツールのサブプロセスに W3C `TRACEPARENT`環境変数を追加。これにより、子プロセスのスパンがClaude Codeのトレースツリーに正しく親子関係を持ちます
- LSP：Claude Codeが初期化リクエストの`clientInfo`を通じて言語サーバーに自身を識別するようになりました
- バックスラッシュでエスケープされたフラグが読み取り専用として自動許可され、任意のコード実行につながる可能性があったBashツールの権限バイパスを修正
- autoモードとbypass-permissionsモードで、複合Bashコマンドが安全性チェックと明示的なaskルールの強制権限プロンプトをバイパスしていた問題を修正
- 環境変数プレフィックス付きの読み取り専用コマンドが、その変数が既知の安全なもの（`LANG`、`TZ`、`NO_COLOR`など）でない限りプロンプトを表示しなかった問題を修正
- `/dev/tcp/...`または`/dev/udp/...`へのリダイレクトが自動許可される代わりにプロンプトを表示しなかった問題を修正
- ストリーミングレスポンスが停止した際、非ストリーミングモードにフォールバックする代わりにタイムアウトしていた問題を修正
- サーバーが小さな`Retry-After`を返した場合、429リトライが約13秒ですべての試行を消費していた問題を修正。指数バックオフが最小値として適用されるようになりました
- MCP OAuthの`oauth.authServerMetadataUrl`設定オーバーライドが、再起動後のトークン更新時に尊重されず、ADFSや類似のIdPに影響していた問題を修正
- kittyキーボードプロトコルがアクティブな場合、xtermとVS Code統合ターミナルで大文字が小文字に変換されていた問題を修正
- macOSのテキスト置換がトリガーワードを削除する代わりに置換テキストを挿入していた問題を修正
- Bash経由で保護されたパスへの書き込みを承認した後、`--dangerously-skip-permissions`がサイレントにaccept-editsモードにダウングレードされていた問題を修正
- 管理者が削除した後も、プロセス再起動までmanaged-settingsの許可ルールがアクティブなままだった問題を修正
- `permissions.additionalDirectories`の変更がセッション中に適用されなかった問題を修正。削除されたディレクトリは即座にアクセスを失い、追加されたディレクトリは再起動なしで機能します
- `additionalDirectories`からディレクトリを削除すると、`--add-dir`経由で渡された同じディレクトリへのアクセスも取り消されていた問題を修正
- `Bash(cmd:*)`と`Bash(git commit *)`のワイルドカード権限ルールが、余分なスペースやタブを含むコマンドにマッチしなかった問題を修正
- `Bash(...)`拒否ルールが、`cd`と他のセグメントを混在させたパイプコマンドに対してプロンプトにダウングレードされていた問題を修正
- `cut -d /`、`paste -d /`、`column -s /`、`awk '{print $1}' file`、および`%`を含むファイル名に対する誤ったBash権限プロンプトを修正
- JavaScriptのprototypeプロパティと一致する名前（例：`toString`）を持つ権限ルールが、`settings.json`をサイレントに無視させていた問題を修正
- `--dangerously-skip-permissions`使用時に、エージェントチームメンバーがリーダーの権限モードを継承しなかった問題を修正
- フルスクリーンモードでMCPツール結果にホバーした際のクラッシュを修正
- フルスクリーンモードで折り返されたURLをコピーする際、改行位置にスペースが挿入されていた問題を修正
- 編集されたファイルが10KBより大きい場合、`--resume`時にファイル編集差分がUIから消えていた問題を修正
- `/resume`ピッカーの複数の問題を修正：`--resume <name>`が編集不可で開く、フィルターリロードが検索状態を消去、空リストが矢印キーを飲み込む、プロジェクト間の古さ、一時的なタスクステータステキストが会話サマリーを置き換える問題
- `/export`が絶対パスと`~`を尊重せず、ユーザー指定の拡張子をサイレントに`.txt`に書き換えていた問題を修正
- `/effort max`が未知または将来のモデルIDに対して拒否されていた問題を修正
- プラグインのfrontmatterの`name`がYAMLのブール値キーワードの場合、スラッシュコマンドピッカーが壊れていた問題を修正
- メッセージの再マウント後にレート制限のアップセルテキストが非表示になっていた問題を修正
- `_meta["anthropic/maxResultSizeChars"]`を持つMCPツールがトークンベースの永続化レイヤーをバイパスしなかった問題を修正
- 前のトランスクリプトがまだ処理中の間にプッシュトゥトークキーを再度押し続けると、ボイスモードが入力に数十個のスペース文字を漏らしていた問題を修正
- `DISABLE_AUTOUPDATER`がnpmベースのインストールでnpmレジストリのバージョンチェックとシンボリックリンクの変更を完全に抑制しなかった問題を修正
- Remote Control権限ハンドラーエントリがセッションの存続期間中保持されていたメモリリークを修正
- エラーで失敗したバックグラウンドサブエージェントが親エージェントに部分的な進捗を報告しなかった問題を修正
- 長いセッションでprompt-typeのStop/SubagentStopフックが失敗し、フック評価APIエラーが実際のメッセージの代わりに「JSON validation failed」と表示されていた問題を修正
- 却下されたフィードバック調査のレンダリングを修正
- Bash `grep -f FILE` / `rg -f FILE`が作業ディレクトリ外のパターンファイルを読み取る際にプロンプトを表示しなかった問題を修正
- 古いサブエージェントworktreeのクリーンアップが、追跡されていないファイルを含むworktreeを削除していた問題を修正
- macOSで`sandbox.network.allowMachLookup`が有効にならなかった問題を修正
- `/resume`フィルターのヒントラベルを改善し、フィルターインジケーターにプロジェクト/worktree/ブランチ名を追加
- フッターインジケーター（Focus、通知）が狭いターミナル幅で折り返す代わりに、モードインジケーター行に留まるように改善
- `/agents`をタブレイアウトで改善：Runningタブはライブサブエージェントを表示し、LibraryタブにはRun agentとView running instanceアクションを追加
- `/reload-plugins`を改善し、再起動なしでプラグイン提供のスキルを取得できるように
- Accept Editsモードを改善し、安全な環境変数やプロセスラッパーでプレフィックスされたファイルシステムコマンドを自動承認するように
- Vimモードを改善：NORMALモードの`j`/`k`が履歴をナビゲートし、入力境界でフッターピルを選択するように
- トランスクリプト内のフックエラーに、`--debug`なしで自己診断できるようstderrの最初の行を含めるように改善
- OTELトレーシングを改善：インタラクションスパンが並行SDK呼び出し下で完全なターンを正しくラップし、ヘッドレスターンがターンごとにスパンを終了するように
- トランスクリプトエントリがストリーミングプレースホルダーの代わりに最終的なトークン使用量を保持するように改善
- `/claude-api`スキルをClaude APIと並んでManaged Agentsをカバーするように更新
- [VSCode] `CLAUDE_CODE_GIT_BASH_PATH`が設定されているか、Gitがデフォルトの場所にインストールされている場合、Windows上で「requires git-bash」という誤検知エラーを修正
- `CLAUDE_CODE_MAX_CONTEXT_TOKENS`が設定されている場合に`DISABLE_COMPACT`を尊重するように修正
- `DISABLE_COMPACT`が設定されている場合、`/compact`ヒントを削除
