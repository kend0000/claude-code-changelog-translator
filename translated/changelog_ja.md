## 2.1.88

- ちらつきのないalt-screen レンダリングと仮想化されたスクロールバックを有効にする `CLAUDE_CODE_NO_FLICKER=1` 環境変数を追加
- auto モードの分類器による拒否後に発火する `PermissionDenied` フックを追加 — `{retry: true}` を返すことでモデルに再試行可能であることを伝えられます
- `@` メンションの入力候補に名前付きサブエージェントを追加
- セッション中にツールスキーマのバイト数が変化することで発生していた、長時間セッションでのプロンプトキャッシュミスを修正
- 多数のファイルを読み込む長時間セッションで、ネストされた CLAUDE.md ファイルが数十回再注入される問題を修正
- Windows で Edit/Write ツールが CRLF を二重化し、Markdown のハードラインブレーク（末尾の2つのスペース）を削除していた問題を修正
- 複数のスキーマを使用するワークフローで約50%の失敗率を引き起こしていた `StructuredOutput` スキーマキャッシュのバグを修正
- 長時間実行されるセッションで、大きな JSON 入力が LRU キャッシュキーとして保持されるメモリリークを修正
- Edit ツールを非常に大きなファイル（1 GiB 超）に使用した際のメモリ不足クラッシュの可能性を修正
- 非常に大きなセッションファイル（50MB 超）からメッセージを削除する際のクラッシュを修正
- 古い CLI バージョンまたは中断された書き込みからのツール結果を含むトランスクリプトで `--resume` がクラッシュする問題を修正
- API がエンタイトルメントエラーを返した際に誤解を招く「レート制限に達しました」メッセージが表示されていた問題を修正 — 実際のエラーと実行可能なヒントを表示するようになりました
- クラッシュ後に LSP サーバーがゾンビ状態になる問題を修正 — セッション再起動まで失敗し続けるのではなく、次のリクエスト時にサーバーが再起動するようになりました
- フックの `if` 条件フィルタリングが複合コマンド（`ls && git push`）や環境変数プレフィックス付きコマンド（`FOO=bar git push`）にマッチしない問題を修正
- CJK や絵文字を含むプロンプト履歴エントリが `~/.claude/history.jsonl` の 4KB 境界に該当した際に黙って削除される問題を修正
- 統計キャッシュフォーマットが変更された際に `/stats` が30日を超える履歴データを失う問題を修正
- `/stats` がサブエージェント/フォークの使用量を除外してトークンを過少カウントしていた問題を修正
- 長時間セッションで上にスクロールした際にスクロールバックが消える問題を修正
- 大量の並列ツール使用中に、折りたたまれた検索/読み取りグループのバッジがターミナルのスクロールバックで重複する問題を修正
- 通知の `invalidates` が現在表示中の通知を即座にクリアしない問題を修正
- 処理中にバックグラウンドメッセージが到着した際、送信後にプロンプトが一時的に消える問題を修正
- 長い `/btw` レスポンスがスクロール不可能な状態で切り取られる問題を修正 — レスポンスがスクロール可能なビューポートでレンダリングされるようになりました
- デーバナーガリーなどの結合記号テキストがアシスタント出力で切り捨てられる問題を修正
- レイアウトシフト後のメインスクリーンターミナルでのレンダリングアーティファクトを修正
- macOS Apple Silicon で音声モードがマイク権限のリクエストに失敗する問題を修正
- 一部の修飾キーの組み合わせバインディングで音声プッシュトゥトークが起動しない問題を修正
- Windows で音声モードが「WebSocket upgrade rejected with HTTP 101」で失敗する問題を修正
- Windows Terminal Preview 1.25 で Shift+Enter が改行を挿入せずに送信してしまう問題を修正
- tmux 内で実行している iTerm2 でストリーミング中に定期的な UI のジッターが発生する問題を修正
- Windows PowerShell 5.1 で `git push` などのコマンドが stderr に進捗を書き込んだ際に、PowerShell ツールが誤って失敗を報告する問題を修正
- SDK エラー結果メッセージ（`error_during_execution`、`error_max_turns`）が説明的なメッセージとともに `is_error: true` を正しく設定するよう修正
- Ctrl+B でセッションをバックグラウンド化した際にタスク通知が失われる問題を修正
- PreToolUse/PostToolUse フックが Write/Edit/Read ツールの `file_path` を絶対パスとして提供しない問題を修正
- PowerShell ツールのプロンプトをバージョンに応じた適切な構文ガイダンス（5.1 vs 7+）で改善
- インタラクティブセッションでは思考サマリーがデフォルトで生成されなくなりました — 復元するには設定で `showThinkingSummaries: true` を設定してください
- auto モードで拒否されたコマンドが通知を表示し、`/permissions` → Recent タブに表示されるようになりました
- `/env` が PowerShell ツールコマンドにも適用されるようになりました（以前は Bash のみに影響）
- `/usage` が Pro および Enterprise プランで冗長な「Current week (Sonnet only)」バーを非表示にするようになりました
- 折りたたまれたツールサマリーが ls/tree/du に対して「Read N files」ではなく「Listed N directories」を表示するようになりました
- 画像ペースト時に末尾のスペースが挿入されなくなりました
- 空のプロンプトに `!command` をペーストすると bash モードに入るようになり、`!` をタイプした際の動作と一致するようになりました

- プロキシがボディを解析せずにセッションごとにリクエストを集約できるよう、API リクエストに `X-Claude-Code-Session-Id` ヘッダーを追加

- v2.1.85 より前に作成されたセッションで `--resume` が「tool_use ids were found without tool_result blocks」で失敗する問題を修正
- 条件付きスキルまたはルールが設定されている場合に、プロジェクトルート外のファイル（例：`~/.claude/CLAUDE.md`）で Write/Edit/Read が失敗する問題を修正
- スキル呼び出しごとに不要な設定ディスク書き込みが発生し、Windows でパフォーマンス問題や設定破損を引き起こす可能性があった問題を修正
- 非常に長いセッションで大きなトランスクリプトファイルを持つ場合に `/feedback` を使用した際のメモリ不足クラッシュの可能性を修正
- `--bare` モードがインタラクティブセッションで MCP ツールを削除し、ターン中にエンキューされたメッセージを黙って破棄する問題を修正
- `c` ショートカットが OAuth ログイン URL の完全な URL ではなく約20文字しかコピーしない問題を修正
- マスクされた入力（例：OAuth コードペースト）が狭いターミナルで複数行にわたる際にトークンの先頭が漏れる問題を修正
- v2.1.83 以降、macOS/Linux で公式マーケットプレイスプラグインスクリプトが「Permission denied」で失敗する問題を修正
- 複数の Claude Code インスタンスを実行し、そのうちの1つで `/model` を使用した際に、ステータスラインが別のセッションのモデルを表示する問題を修正
- 長い会話の最下部でホイールスクロールまたはクリック選択後、スクロールが新しいメッセージを追従しない問題を修正
- `/plugin` アンインストールダイアログを修正：`n` を押すとデータディレクトリを保持したままプラグインが正しくアンインストールされるようになりました
- クリック後に Enter を押すとレスポンスが到着するまでトランスクリプトが空白のままになるリグレッションを修正
- キーワードを削除した後も `ultrathink` ヒントが残る問題を修正
- markdown/ハイライトレンダリングキャッシュが完全なコンテンツ文字列を保持することによる、長時間セッションでのメモリ増加を修正
- 多数の claude.ai MCP コネクタが設定されている場合の起動時イベントループストールを削減（macOS キーチェーンキャッシュを5秒から30秒に延長）
- `@` でファイルをメンションする際のトークンオーバーヘッドを削減 — 生の文字列コンテンツが JSON エスケープされなくなりました
- ツール説明から動的コンテンツを削除することで、Bedrock、Vertex、Foundry ユーザーのプロンプトキャッシュヒット率を改善
- 「Saved N memories」通知のメモリファイル名がホバー時にハイライトされ、クリックで開くようになりました
- `/skills` リストのスキル説明がコンテキスト使用量を削減するため250文字に制限されるようになりました
- `/skills` メニューがスキャンしやすいようアルファベット順にソートされるよう変更
- auto モードがプラン制限により無効化されている場合に「unavailable for your plan」を表示するようになりました（以前は「temporarily unavailable」）
- [VSCode] 長時間実行される操作中に拡張機能が誤って「Not responding」を表示する問題を修正
- [VSCode] OAuth トークンが更新された後（ログインから8時間後）、拡張機能が Max プランユーザーをデフォルトで Sonnet にする問題を修正
- Read ツールがコンパクトな行番号フォーマットを使用し、変更されていない再読み取りを重複排除することで、トークン使用量を削減するようになりました

## 2.1.85

- 1つのヘルパーで複数のサーバーに対応できるよう、MCP `headersHelper` スクリプトに `CLAUDE_CODE_MCP_SERVER_NAME` および `CLAUDE_CODE_MCP_SERVER_URL` 環境変数を追加
- パーミッションルール構文（例：`Bash(git *)`）を使用してフックの実行タイミングをフィルタリングする条件付き `if` フィールドを追加し、プロセス生成のオーバーヘッドを削減
- スケジュールされたタスク（`/loop`、`CronCreate`）が発火した際のトランスクリプトにタイムスタンプマーカーを追加
- 画像をペーストした際の `[Image #N]` プレースホルダーの後に末尾スペースを追加
- ディープリンククエリ（`claude-cli://open?q=…`）が最大5,000文字をサポートし、長い事前入力プロンプトには「scroll to review」警告が表示されるようになりました
- MCP OAuth が RFC 9728 Protected Resource Metadata ディスカバリーに従って認可サーバーを見つけるようになりました
- 組織ポリシー（`managed-settings.json`）によってブロックされたプラグインはインストールまたは有効化できなくなり、マーケットプレイスビューから非表示になります
- PreToolUse フックが `permissionDecision: "allow"` と並行して `updatedInput` を返すことで `AskUserQuestion` を満たせるようになり、独自の UI で回答を収集するヘッドレス統合が可能になりました
- OpenTelemetry tool_result イベントの `tool_parameters` が `OTEL_LOG_TOOL_DETAILS=1` の背後にゲートされるようになりました
- 会話が大きくなりすぎてコンパクトリクエスト自体が収まらない場合に `/compact` が「context exceeded」で失敗する問題を修正
- プラグインのインストール場所が設定で宣言されている場所と異なる場合に `/plugin enable` および `/plugin disable` が失敗する問題を修正
- `WorktreeCreate` フックが実行される前に、非 git リポジトリで `--worktree` がエラーで終了する問題を修正
- `deniedMcpServers` 設定が claude.ai MCP サーバーをブロックしない問題を修正
- マルチモニター設定で computer-use ツールの `switch_display` が「not available in this session」を返す問題を修正
